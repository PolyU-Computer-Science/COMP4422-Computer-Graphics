# COMP4422 M1 — Geometry & Camera (Member A)

Run from the repo root (needs a local server because of ES modules + fetching the .obj):

    python -m http.server 8000     # then open http://localhost:8000  (macOS/Linux: python3)
    npx serve                      # alternative, then open the URL it prints

Optional tests (Node 18+):

    node test-math.js              # Vec3 / Mat4 / OBJ parser
    node test-prims.mjs            # primitives: UV counts and triangle winding
    node test-camera.mjs           # follow camera ends up behind its subject; camera stays above the floor

| M1 requirement | Where |
|---|---|
| Own Vec3 / Mat4 library | `math/Vec3.js`, `math/Mat4.js` (column-major, translation at 12–14) |
| Indexed meshes, drawn with `drawElements` | `js/mesh.js` (VAO + VBO + EBO), `js/primitives.js` (cube 24v/36i, sphere, torus, plane) |
| Loaded .obj | `js/obj-loader.js` + `assets/knot.obj` (drop any .obj onto the page) |
| Model–view–projection, perspective camera | `js/main.js` (`P·V·M` on CPU → `uMVP`), `Mat4.lookAt`, `Mat4.perspective` |
| Depth test on | `gl.enable(DEPTH_TEST)` + depth cleared each frame; `Z` toggles it to show why it matters |
| Controllable camera | `js/camera.js` orbit camera: drag, wheel, WASD/QE, arrows, `[` `]` FOV, `R` reset; `F` third-person follow |

Keys: `F` follow camera, `Z` depth test, `C` back-face culling, `U` UV checker view, `R` reset.

Follow mode tracks a placeholder swimmer (`swimmer(t)` in `js/main.js`). To follow the real player, call
`camera.follow(position, heading, dt)` each frame, where `heading` is the yaw of the player's forward direction
(forward = `(sin h, 0, cos h)`). Dragging still orbits around the player; the camera stays above the floor.

## Conventions for M2 / M3 / M4

- Vertex format: `location 0 = aPos (vec3)`, `1 = aNormal (vec3)`, `2 = aTexCoord (vec2)`, interleaved, stride 32 bytes.
  Meshes without UVs get (0,0).
- Matrices are column-major `Float32Array(16)`; `Mat4.multiply(a, b)` is `a * b` (b is applied first).
  Upload with `gl.uniformMatrix4fv(loc, false, m)`.
- Triangles wind counter-clockwise seen from outside.
- `parseOBJ` / `loadOBJ` recentre the model and scale it to fit a unit sphere by default.
  Pass `{ normalize: false }` to keep the file's own coordinates.
- UVs use v = 0 at the bottom edge. When uploading an image as a texture, call
  `gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, true)` first or it appears upside-down.
- Uniforms `js/main.js` sets for every draw; a shader only has to declare the ones it uses:

  | Uniform | Type | Meaning |
  |---|---|---|
  | `uMVP` | mat4 | `P * V * M` |
  | `uModel` | mat4 | object → world |
  | `uView`, `uProj` | mat4 | camera view and perspective projection |
  | `uNormalMatrix` | mat3 | inverse-transpose of `uModel` (`Mat4.normalMatrix`), for world-space normals |
  | `uEyePos` | vec3 | camera position in world space |

  The vertex shader outputs `vNormal` and `vWorldPos` in world space, plus `vUV`.

`assets/knot.obj` is generated by `tools/gen_knot.py` (placeholder model; swap for the team's real asset).

Shaders here are intentionally minimal (normal colours); Member B replaces them in M2.
